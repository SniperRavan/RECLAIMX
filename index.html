Hybrid Scoring Engine
Text similarity + image signal + location proximity + time decay — combined into one weighted confidence score. Image embedding via pgvector planned for v2.
Privacy First
Only the item name is publicly visible. Descriptions, images, and personal details are stored privately and only used for verified claim checks.
Fraud Prevention
3-question dynamic verification from private report attributes. 3 failed attempts trigger suspension and fraud logging.
Trust Score System
Earn points for successful returns. Bronze → Silver → Gold. Higher trust means faster claim processing.
Works Offline
Full PWA support. Report items offline — submissions sync automatically when you reconnect to the network.
Multi-Campus Ready
campus_id field in every table enables multi-campus matching without any schema changes. It's a filter, not a redesign.
